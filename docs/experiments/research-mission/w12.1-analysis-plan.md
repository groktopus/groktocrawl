# W12.1 Research Mission analysis plan

Status: **declared before measurement**

## Questions

1. Does mission enforcement improve difficult-case obligation coverage?
2. Does it reduce scope violations and inappropriate closure?
3. Are gains caused by better intake, downstream enforcement, or both?
4. Which strata benefit, and which incur only ceremony?
5. What latency, model-call, token, and correction burden buys the effect?
6. Does the contract cause over-constraint, needless clarification, or
   over-abstention?

## Primary comparisons

For every repetition, calculate the paired treatment-minus-control change in
weighted coverage and decision usefulness, and the paired relative change in
scope violations. Summarize medians and full case-level distributions by
stratum. With only two cases per stratum, confidence intervals and model-graded
scores describe uncertainty; they do not manufacture population-level proof.
The frozen practical-effect gate remains the decision boundary.

Analyze intake separately. Report exact mission-field recall, hard-boundary
losses, inventions, clarification precision, and correction turns. Then examine
whether intake failures predict downstream failures without treating that
association as causal proof.

## Competing explanations

- **Prompt-length effect:** equivalent prose performs as well as typed
  enforcement; the schema itself adds no value.
- **Evaluator favoritism:** graders prefer visibly structured answers even when
  evidence closure is unchanged.
- **Extra-work effect:** treatment wins only because it makes more calls or
  retrieves more sources despite frozen ceilings.
- **Ambiguity selection:** gains occur only where the reference author encoded a
  preferred interpretation.
- **Over-constraint:** the mission blocks useful discoveries or increases
  abstention on answerable cases.
- **Instability:** mean gains hide inconsistent repetitions or one influential
  case.

Use equivalence checks, sealed rendering, work accounting, clarification logs,
stratum reporting, and leave-one-case-out analysis to test these explanations.

The primary analysis gives a partial obligation one-half credit. The declared
conservative sensitivity counts partial grades as open. Equal-weight coverage,
leave-one-case-out results for each ambiguous and compound case, failed-call
missing and worst-case views, original versus independent regrades, and intake
latency/cost split by clarification action are emitted in the machine-readable
outcome. A fully valid run has no failed primary calls; in that case the missing
and worst-case views are explicitly recorded as identical to the primary view.

A terminal failure does not invalidate a run unless its lane exceeds the 10%
failure guardrail. Failed candidates are not graded. For the conservative view,
a missing treatment receives zero coverage, one scope violation, usefulness
zero, and a hard-boundary failure; a missing control receives full coverage, no
scope violation, and usefulness 100. Adoption is prohibited when the treatment
effect gate fails under this conservative assignment.

## Decision outputs

The outcome report must select exactly one disposition:

1. reject the Research Mission contract;
2. revise and rerun because a named validity problem prevents a decision;
3. adopt it only for named difficult strata with an explicit trigger;
4. adopt it universally for the tested domain.

Any adoption states the schema version, trigger, clarification policy, hard
bounds, observed benefit and harm, rollback path, and limits of generalization.
The roadmap and a new or superseding ADR are updated only after the result is
accepted.
