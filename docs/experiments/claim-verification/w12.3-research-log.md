# W12.3 independent claim-verification research log

## 2026-09-19 — scope and method

Issue #323 was re-read from the live tracker after W12.2 merged. Existing
`verification.py` and publication gates were inspected first. They correctly bind
fixture judgments to exact inputs but explicitly do not provide a semantic oracle
or authenticated model verifier. W12.3 therefore adds an isolated experimental
boundary instead of changing the publication path before value is established.

The research-methodology skill was applied as a technical verification study. The
durable destination is this tracked experiment package and its eventual evidence
packet. The corpus will preserve exact source spans and sealed judgments separately
from synthesis. Excluded runs, weak evidence, and inaccessible model routes will be
recorded here rather than silently discarded.

Hermes one-shot was evaluated first because it provides an independently named
Luna route. The route worked, but a two-field smoke response consumed about
37,000 input tokens from the full agent shell even with user configuration and
rules disabled. That path is excluded before measurement because it would test
irrelevant agent scaffolding and spend substantially more subscription capacity.

The replacement preflight used the thin local LiteLLM `general` route. Independence
comes from fixed hand-authored claims, deterministic control selection, sealed
references, blinded inputs, and mechanical scoring rather than from asking a claim
generator to review itself. The one-case preflight completed in one call, returned
the exact schema, correctly supported the valid retention claim, and took 1.7
seconds. It remains outside the measured tree.

## 2026-09-19 — excluded v1 launch

V1 was stopped after 24 allocated trials had reached terminal records: 20 completed
and four failed. Four of 36 allocated trials is 11.1%, already above the frozen
below-10% guardrail. Continuing could not make the launch eligible and would have
wasted model capacity.

The excluded tree contains 53 files. Its 6,138-byte canonical
content-digest-plus-relative-path manifest has SHA-256
`00d6b80a39e4fa56afd949446b89a0c93978b0e1fae1184a7fb242efbc1b07c9`.
The failures were `contradicted-delivery-r2`, `contradicted-delivery-r3`,
`stale-limit-r2`, and `stale-limit-r3`. Three exposed the hidden cross-list
uniqueness mismatch; one repeatedly used an unrelated response template. No v1
record is eligible for the W12.3 comparison.

The v2 targeted preflight reran one delivery-contradiction case and one stale-limit
case outside the measured tree. Both produced valid traceable verdicts under the
corrected subset contract. V2 is eligible for a new freeze without reusing any v1
result.

## 2026-09-19 — v2 final result

V2 completed all 36 trials with zero failures and one call per trial. The verifier
eliminated every critical false accept, caught both contradiction cases in every
repetition, preserved every publishable claim, cited every required span, and did
not follow the hostile source instruction. All three repetition quality gates
passed. Mean latency was 11.9 seconds and high-risk p95 latency was 22.3 seconds.

The validated v2 tree contains 75 files and 500,990 content bytes. Its 8,625-byte
canonical content-digest-plus-relative-path manifest has SHA-256
`026e657eda23dfe5d034965efc805a3649d25d56b308e28caae91feb479912fa`.
The frozen result adopts the bounded verifier contract for source-bound publication
candidates behind an experimental rollout and live calibration boundary.
