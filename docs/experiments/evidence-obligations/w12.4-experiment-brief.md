# W12.4 evidence-obligation continuation experiment

## Question

Does continuation tied to one explicit, still-open evidence obligation behave
better than a fixed pass or W10-style generic adaptive continuation?

This experiment isolates the control rule. It replays the same frozen candidate
sets through all three arms. It does not estimate how often a live search engine
will find the modeled evidence.

## Intervention

- `fixed`: execute the initial query and stop.
- `w10_diagnostic`: execute the initial query and every bounded generic follow-up.
- `obligation`: select the highest-importance open obligation, execute only its
  registered query, and stop after closure, zero material gain, or the shared
  three-query limit.

An acquired candidate is admitted only when it is non-derivative, canonical, and
material. An obligation closes only when every candidate named by its frozen
closure rule has been admitted.

## Scope correction after W12.1

The case profiles are narrow evaluator inputs, not a universal Research Mission
contract. W12.1 rejected mandatory model-authored normalization. A future caller
may supply an obligation profile when its task warrants one; ordinary questions
remain valid without it.

## Interpretation boundary

Passing establishes that the typed ledger, proposal binding, admission rule, and
deterministic stop can enforce the intended behavior. It supports an experimental
continuation option. It does not establish a production effect size, automatic
obligation discovery, or universal adaptive search.
